# DevJhonGomez | Portafolio Profesional

Un portafolio moderno y responsive creado con React, TypeScript, Vite y Tailwind CSS para mostrar mis proyectos y habilidades como desarrollador.

![DevJhonGomez Portafolio](./public/preview.png)

## 🚀 Características

- ✅ Diseño responsive y moderno
- ✅ Animaciones suaves con Framer Motion
- ✅ Modo oscuro / claro
- ✅ Optimizado para SEO
- ✅ Código limpio y mantenible
- ✅ Construido con TypeScript

## 🛠️ Tecnologías

- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- Vite
- React Icons

## 🔧 Instalación

1. Clona este repositorio
   ```bash
   git clone https://github.com/ingjhonhernandezgomez/PortafolioDevJhonGomez.git
   ```

2. Navega al directorio del proyecto
   ```bash
   cd PortafolioDevJhonGomez
   ```

3. Instala las dependencias
   ```bash
   npm install
   ```

4. Inicia el servidor de desarrollo
   ```bash
   npm run dev
   ```

## 📦 Estructura del Proyecto

```
src/
├── assets/           # Recursos estáticos (imágenes, íconos, documentos)
│   └── images/       # Miniaturas y gráficos de los proyectos
├── components/
│   ├── layout/       # Componentes de estructura (Navbar, ThemeToggle)
│   ├── sections/     # Secciones principales (Hero, About, Skills, Projects, Contact)
│   └── ui/           # Componentes UI reutilizables
├── App.tsx           # Orquesta las secciones principales
├── index.css         # Estilos globales basados en Tailwind
└── main.tsx          # Punto de entrada de la aplicación
```

## 🚀 Despliegue

Para construir el proyecto para producción:

```bash
npm run build
```

Para previsualizar la build:

```bash
npm run preview
```
